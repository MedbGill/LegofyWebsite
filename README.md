# LegofyWebsite
A typescript implementation of Legofy (see credits below) to allow for easy Lego image generation for anyone with a browser instead of requiring python/node CLI.

The final product will be entirely client-side processing of the Lego image, with recommended image options and customization based on the original projects with new features such as different shaped bricks, a list of bricks used, and updating the colors to the current set of available Lego colors. To make the Lego image more useful as a decorative art piece, the tool will also have recommended base plates and a frame design (that the user can decide between/toggle off as they wish). Finally, this will attach to a BrickLink API call to price out the build if the user wishes to build the image IRL, with 3 options: Pure 1x1 bricks, the least number of bricks, and the cheapest (based on price guides) build.

# Tools
Node.js, Typescript, React
