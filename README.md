# LegofyWebsite
A typescript implementation of Legofy (see credits below) to allow for easy Lego image generation for anyone with a browser instead of requiring python/node CLI.

The final product will be entirely client-side processing of the Lego image, with recommended image options and customization based on the original projects with new features such as different shaped bricks, a list of bricks used, and updating the colors to the current set of available Lego colors. To make the Lego image more useful as a decorative art piece, the tool will also have recommended base plates and a frame design (that the user can decide between/toggle off as they wish). Finally, the user can decide can decide between wanting the image in just 1x1 bricks, or using the fewest bricks with easily acquired brick shapes based on the amounts found on BrickLink.
